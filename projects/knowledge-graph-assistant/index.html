How the assistant thinks

It matches entity names, checks the relationship list, and builds an answer from graph facts.

QUERY PIPELINE
1. Identify entity names in the question
2. Retrieve matching nodes and edges
3. Use breadth-first search for a path
4. Explain the path with relationship labels

A production GraphRAG system can add a graph database, semantic retrieval and a language model.

How this project works

Follow the data from stored facts to the answer displayed above.

01 · DATAEntities and relationships are stored as JavaScript objects.
02 · GRAPHSVG draws each entity as a node and each relationship as an edge.
03 · RETRIEVALSearch filters nodes; BFS finds a shortest connection path.
04 · RESPONSEThe interface explains the path using real relationship labels.
HTML · CSS · SVG · Vanilla JavaScript · Sample educational dataset · No external API required
