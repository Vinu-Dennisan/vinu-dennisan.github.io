# Student Portal

A small React front-end demo for managing student records.

## Run locally

From this directory, install dependencies and start the development server:

```bash
npm install
npm start
```

## Production build

```bash
npm run build
```

## Features

- Add a student name, course and optional email address.
- Search student records.
- Remove records.
- Keep records after refresh using browser local storage.

## Important limitation

This is a front-end demonstration. Data is stored only in the current browser on the current device. There is no backend, shared database, authentication or role-based access control. Do not use it for confidential or official student information.
